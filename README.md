# FitTrack – Fitness Management System
## About the Project
FitTrack is a fitness management web application that helps users manage their personal information, set fitness goals, track their weight, and submit feedback.


## Features
* User registration and login
* User profile management
* Fitness goal and target weight management
* Feedback submission with star ratings
* MySQL database for storing user information

## Technologies Used
* HTML
* CSS
* JavaScript
* MySQL


## Installation and Setup
1. Clone or download the project.
2. Install MySQL on your system.
3. Open MySQL Workbench or your MySQL command line.
4. Execute the provided SQL script to create the `fittrack` database and its tables.
5. Open the project in your code editor.
6. Run the application using a local server.


## Database
The project uses a MySQL database named "fittrack"
* **Users:** Stores user details and fitness information.
* **Feedback:** Stores user ratings, categories, and comments.
